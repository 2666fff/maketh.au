Is the website really $299 AUD?

Yes. The fixed $299 package covers up to 10 client-supplied content pages within the listed scope. Requirements outside that scope are quoted before work begins.

What is included in the $399 website package?

It covers more than 10 and up to 30 client-supplied content pages, responsive design, basic search metadata, first-year basic server hosting and complete source code. Domain registration is separate.

What counts as one website page?

One page is one public URL with a distinct content purpose. Product databases, repeated catalogue records and custom application screens are assessed as functions, not counted as ordinary content pages.

What does the first-year domain inclusion mean?

The $299 package covers one standard available domain registration for year one. Premium, special, restricted or already-owned domains are not included. The $399 package includes server hosting but not domain registration.
